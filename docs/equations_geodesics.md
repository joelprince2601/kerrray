# Geodesic equations (Phase 2)

Null geodesics of the Kerr metric in Boyer-Lindquist coordinates: the two
formulations implemented in `src/kerrray/geodesics/equations.py`, the
conserved quantities of `src/kerrray/photons/constants.py`, the separated
potentials used by `src/kerrray/geodesics/initial_conditions.py`, and the
mapping from every equation to the code and the test that verifies it. This
chapter is merged into `docs/equations.md` at integration. Conventions are
those of `docs/equations.md` section 1 and `docs/architecture.md` section 1:
G = c = 1, signature (-, +, +, +), coordinates (t, r, θ, φ) with index order
0..3, a = spin · M, Σ = r² + a² cos²θ, Δ = r² − 2Mr + a².

## 1. Hamiltonian form (primary)

Geodesics are the trajectories generated by the super-Hamiltonian

    H(x, p) = (1/2) g^{μν}(x) p_μ p_ν

(Misner, Thorne and Wheeler 1973, *Gravitation*, section 25.2 for the
super-Hamiltonian of geodesic motion and section 33.5 for its use in Kerr;
Carter 1968, Phys. Rev. 174, 1559; Chandrasekhar 1983, *The Mathematical
Theory of Black Holes*, chapter 7). Hamilton's equations in the affine
parameter λ are

    dx^μ/dλ =  ∂H/∂p_μ =  g^{μν} p_ν
    dp_μ/dλ = −∂H/∂x^μ = −(1/2) (∂_μ g^{αβ}) p_α p_β

and a photon satisfies H = 0. The Kerr metric depends on r and θ only, so the
only non-zero derivatives are ∂_r g^{αβ} and ∂_θ g^{αβ}
(`kerrray.geometry.inverse_metric_derivatives`, verified there against
SymPy), and p_t and p_φ are constant *in the ODE itself*. Written out with the
five non-zero contravariant components:

    dt/dλ      = g^{tt} p_t + g^{tφ} p_φ
    dr/dλ      = g^{rr} p_r
    dθ/dλ      = g^{θθ} p_θ
    dφ/dλ      = g^{tφ} p_t + g^{φφ} p_φ
    dp_t/dλ    = 0
    dp_r/dλ    = −(1/2) [∂_r g^{tt} p_t² + 2 ∂_r g^{tφ} p_t p_φ + ∂_r g^{rr} p_r² + ∂_r g^{θθ} p_θ² + ∂_r g^{φφ} p_φ²]
    dp_θ/dλ    = −(1/2) [∂_θ g^{tt} p_t² + 2 ∂_θ g^{tφ} p_t p_φ + ∂_θ g^{rr} p_r² + ∂_θ g^{θθ} p_θ² + ∂_θ g^{φφ} p_φ²]
    dp_φ/dλ    = 0

The state vector is `y = [t, r, θ, φ, p_t, p_r, p_θ, p_φ]` (covariant
momenta; `docs/architecture.md` section 1).

**Polar axis.** g^{φφ} = 1/(Σ sin²θ) − a²/(ΣΔ) and its derivatives diverge on
the axis. In the equations they only ever multiply p_φ = L_z. For rays with
exactly L_z = 0 the products vanish identically, so the implementation sets
those coefficients to zero on such rays and obtains the finite limit instead
of 0 · ∞. Rays with L_z ≠ 0 never reach the axis (section 4: Θ(θ) < 0 there),
so a numerical state within |sin θ| < 10⁻¹² of the axis with L_z ≠ 0 is
classified `OUT_OF_DOMAIN` (`docs/numerical_methods.md`).

## 2. Christoffel form (cross-check only)

PROJECT.md section 8 states the geodesic equation in its second-order form,

    d²x^μ/dλ² + Γ^μ_{αβ} (dx^α/dλ)(dx^β/dλ) = 0,     g_{μν} (dx^μ/dλ)(dx^ν/dλ) = 0,

(the geodesic equation, MTW 1973 chapter 10, Carroll 2004 section 3.3; Γ from
`kerrray.geometry.christoffel`, verified
against its definition symbolically). As a first-order system for
`z = [x^μ, u^μ]` with u^μ = dx^μ/dλ:

    dx^μ/dλ = u^μ,      du^μ/dλ = −Γ^μ_{αβ} u^α u^β.

The two forms are related by the metric, p_μ = g_{μν} u^ν and
u^μ = g^{μν} p_ν (`hamiltonian_to_christoffel_state`,
`christoffel_to_hamiltonian_state`). Substituting u^μ = g^{μν} p_ν into the
second-order equation and using ∂_μ g^{αβ} = −g^{αρ} g^{βσ} ∂_μ g_{ρσ}
reproduces Hamilton's equations; the code checks this numerically by
integrating the same ray in both forms (`tests/test_geodesics.py`, agreement
9 × 10⁻¹² at λ = 60 with DOP853 at rtol 10⁻¹²). The Christoffel form is not
used on the hot path: see `docs/numerical_methods.md` section 1 for the
comparison.

## 3. Conserved quantities

Stationarity (∂_t g = 0) and axisymmetry (∂_φ g = 0) make the conjugate
momenta constants of motion (Carter 1968; Bardeen, Press and Teukolsky 1972,
ApJ 178, 347, section II; MTW section 33.5):

    E   = −p_t        energy at infinity      (future-directed photons: E > 0 outside the ergosphere)
    L_z =  p_φ        axial angular momentum

Separability of the Hamilton-Jacobi equation (Carter 1968) gives the third
constant. For null geodesics (μ = 0) it is

    Q = p_θ² + cos²θ [ L_z² / sin²θ − a² E² ]

(BPT 1972 eq. 2.10 with μ = 0; `docs/architecture.md` section 1; Chandrasekhar
1983 chapter 7 writes the same constant as 𝒬). The null constraint is
H = 0 itself. Two evaluations are implemented: `null_constraint(st, y)`
(H from the inverse metric) and `null_constraint_from_rhs(y, dy/dλ)` =
(1/2) p_μ dx^μ/dλ, which is identical because dx^μ/dλ = g^{μν} p_ν and is
what the integrators use (no extra metric evaluation).

The consistency of Q with the metric follows from the identity (section 4)

    2 Σ H = (Δ p_r² − R(r)/Δ) + (p_θ² − Θ(θ)),

which holds for *any* p_μ and any (E, L_z, Q) with E = −p_t, L_z = p_φ. It is
verified symbolically at 40-digit precision in `tests/test_conservation.py`.
Since Q appears only through R and Θ, a null state (H = 0) with
p_θ² = Θ(θ) automatically has Δ² p_r² = R(r), and conversely.

Prograde/retrograde: a photon is *prograde* when a · L_z > 0 (`docs/
architecture.md`); for a = 0 prograde means L_z > 0.

## 4. Separated potentials

With the constants above, Carter's separated first-order equations for null
geodesics are (BPT 1972 eqs. 2.9-2.10 with μ = 0; Chandrasekhar 1983 chapter
7; `docs/architecture.md` section 1.2 in the ξ = L_z/E, η = Q/E² form)

    Σ dr/dλ = ± sqrt(R(r)),        R(r) = [E (r² + a²) − a L_z]² − Δ [Q + (L_z − a E)²]
    Σ dθ/dλ = ± sqrt(Θ(θ)),        Θ(θ) = Q − cos²θ [ L_z² / sin²θ − a² E² ]

Because dr/dλ = g^{rr} p_r = (Δ/Σ) p_r and dθ/dλ = p_θ/Σ, the covariant
momenta of a photon with given constants are

    p_r = ± sqrt(R) / Δ,     p_θ = ± sqrt(Θ),     p_t = −E,     p_φ = L_z.

This is what `photon_from_constants` evaluates (it raises when R or Θ is
negative beyond round-off: the constants are then inconsistent with a
photon at that point). Both potentials are homogeneous of degree two in
(E, L_z, sqrt(Q)), which is why E = 1 loses no generality.

Derivation of the identity of section 3 (also the verification of R and Θ
against the metric): expanding 2ΣH with the closed-form inverse metric gives

    2 Σ H = Δ p_r² − [E (r² + a²) − a L_z]² / Δ + p_θ² + (L_z − a E sin²θ)² / sin²θ,

and (L_z − a E sin²θ)²/sin²θ = (L_z − aE)² + cos²θ (L_z²/sin²θ − a²E²) =
(L_z − aE)² + Q − Θ, while −[E(r²+a²) − aL_z]²/Δ = −R/Δ − Q − (L_z − aE)².
Adding gives the stated identity.

Consequences used by the code and the classifier:

* Θ(θ) → −∞ as sin θ → 0 unless L_z = 0: rays with L_z ≠ 0 turn before the
  axis (sin²θ ≥ L_z²/(Q + a²E² + L_z²)); rays with L_z = 0 may cross it.
* R(r) > 0 as Δ → 0⁺ (R → [E(r₊² + a²) − aL_z]² ≥ 0): no turning points
  exist in a neighbourhood of the horizon, so an inward-moving ray close to
  r₊ is captured (`docs/numerical_methods.md` section 4).
* Equatorial rays (θ = π/2, p_θ = 0) have Q = 0 exactly and stay equatorial,
  since every ∂_θ g^{αβ} carries a factor sin 2θ.

## 5. Special initial conditions

* `equatorial_photon(st, r0, b, inward, prograde, E)`: θ = π/2, Q = 0,
  p_φ = ± b E with the prograde sign rule, p_t = −E, p_r = ∓ sqrt(R)/Δ.
  The impact parameter is b = |L_z|/E (exact for a = 0; for a ≠ 0 it is the
  same combination of the constants).
* `tangential_photon(st, r0, prograde, E)`: p_r = p_θ = 0 in the equatorial
  plane. R(r0) = 0 with Q = 0 reads E(r0² + a²) − a L_z = s sqrt(Δ) (L_z − aE)
  with s = ±1, hence

      L_z = E [ (r0² + a²) + s a sqrt(Δ) ] / ( a + s sqrt(Δ) ),

  which for a = 0 is L_z = s E r0 / sqrt(1 − 2M/r0), i.e. the familiar
  b = r0 / sqrt(1 − 2M/r0) (equivalently b² = −g^{tt}/g^{φφ} at r0, checked
  in `tests/test_null_condition.py`). s = +1 is the root with L_z > 0 at
  large radius (prograde for a ≥ 0). Inside the equatorial ergosphere
  (r0 < 2M, a ≠ 0) both roots have a L_z > 0 and the s = −1 root is singular
  at r0 = 2M, where the tangential null direction is the Killing direction
  ∂_t (E = 0, L_z ≠ 0); the constructor raises there.
* `null_momentum_pt(st, x, p_r, p_θ, p_φ, future_directed)`: solves the null
  condition as a quadratic in p_t,

      g^{tt} p_t² + 2 g^{tφ} p_φ p_t + C = 0,   C = g^{rr} p_r² + g^{θθ} p_θ² + g^{φφ} p_φ²,
      p_t = [ −g^{tφ} p_φ ∓ sqrt(D) ] / g^{tt},   D = (g^{tφ} p_φ)² − g^{tt} C.

  For either root dt/dλ = g^{tt} p_t + g^{tφ} p_φ = ± sqrt(D), so the upper
  sign is the future-directed root (dt/dλ > 0). Outside the ergosphere this
  coincides with E > 0 (`docs/architecture.md` section 1); inside it a
  future-directed photon may have E < 0 (Penrose process), which is why the
  code selects by the sign of dt/dλ rather than of E (decision flagged for
  `docs/decisions.md`). D ≥ 0 and g^{tt} < 0 hold everywhere outside the
  horizon; the function raises otherwise.

## 6. Time reversal and backward ray tracing

The equations are invariant under (λ, p_μ) → (−λ, −p_μ): the right-hand side
is odd in p for dx/dλ and even for dp/dλ. Reversing the momentum at the end
of a ray and integrating forward in λ therefore retraces it exactly (the
camera's backward tracing; `tests/test_integrators.py` returns to the start
to 10⁻⁷ after 80 M of affine parameter at rtol 10⁻¹⁰).
